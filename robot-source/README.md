# Robot source assets

This directory preserves the source model and all 18 STL files used by the web
simulator. The browser copies live under `public/models/s6lr`.

`tracking-controller/` contains the authoritative working inputs copied from
`../Tracking_controller`: `S6LR_v1.xml`, `locomotion.py`, `oscillator.py`, and
`run_robot_no_rl.py`.

`hexapod.urdf` is generated by `scripts/build-corrected-urdf.mjs`. It converts
the nested MJCF joint anchors into parent-relative URDF origins and applies the
opposite visual offsets required by the CAD-coordinate STL files. This avoids
the previous double translation that assembled the legs inside the torso.

Only the two high-density servo meshes are decimated for browser delivery.
They are each instanced six times by the URDF, so reducing those copies has the
largest impact without changing the robot dimensions or kinematics.

To rebuild the optimized copies:

```bash
python -m pip install -r scripts/requirements-mesh.txt
python scripts/optimize_meshes.py
```
